# linux-project TASK-1 


The objective of this assignment is to hands-on experience in creating a basic static website using Linux,
Apache web server, HTML, and CSS.
By completing this assignment, we will learn how to set up a web server, create website files, and
configure the server to serve the website.

**Instructions:**

**Linux Environment:**
*you can use a virtual machine or an online Linux terminal to complete the tasks.
*Install Apache web server and ensure it is running.

**Website Creation:**
*Create a directory named "mywebsite" to store your website files.
*Inside the "mywebsite" directory, create an HTML file named "index.html" and a CSS file named
"style.css."

**HTML File (index.html):**
*Build a simple static website with the following components:
*A header containing a title and a navigation menu (Home, About, Contact).
*A main content section with two paragraphs introducing the website.
*A footer with a copyright notice.

**CSS File (style.css):**
*Style the website components (header, navigation, main, and footer) using CSS properties.
*Apply suitable colors, fonts, margins, and padding to enhance the website's appearance.

**Web Server Configuration:**
*Copy the "index.html" and "style.css" files from the "mywebsite" directory to the appropriate
*location on the Apache web server.
*Ensure that the web server has the necessary permissions to access and serve the files.

**Website Testing:**
*Start the Apache web server.
*Open a web browser and enter the IP address or domain name of your Linux machine in the address bar.
*Verify that the static website is displayed correctly in the browser.
